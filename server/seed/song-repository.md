## Praise
- Progression: Intro (EG) → Verse 1 (Keys) → Verse 2 (Acoustic/Keys) → Pre-Chorus → Chorus 1 (EG) → Verse 3 (Acoustic/Keys) → Verse 4 (Acoustic/Keys) → Pre-Chorus → Chorus 1 (EG) → Chorus 2 → Interlude → Interlude → Bridge (Keys) → Bridge (Bass) → Chorus 1 Breakdown (EG) → Chorus 1 All In → Chorus 2 → Chorus 2 → Instrumental (EG) → Instrumental → Refrain x4 → Ending

Opens on EG riff; quieter/stirring verses, bigger choruses, back down for verses 3–4. Bridges build to a breakdown (EG riff) into an all-in jam through the end. Aggressive EG in the instrumental.
